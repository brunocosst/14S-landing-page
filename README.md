# 14S Tecnologia — Landing Page

Redesign conceitual da página institucional da 14S Tecnologia, desenvolvido como projeto de estudo utilizando HTML e CSS puro.

## Tecnologias

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Estrutura

```text
14s-premium-site/
├── index.html
├── style.css
└── README.md
```

## Como executar

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.

> Projeto de estudo / redesign conceitual. Não representa uma publicação oficial da empresa.
